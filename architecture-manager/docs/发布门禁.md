# 管理台发布门禁（2026-10-15 钉死）

本文件是 `versions/管理台测试充分性评估与补测P表-20261015.md` 的 P1.4 产物。它由 2026-10-15 全量审计确立：此前**没有 CI、没有 git hook**，`npm test` 与 `npm run conform` 全靠人手跑，且套件默认带 6 个红 ⇒ 门禁形同虚设。

## 两条命令，各管一段

| 场景 | 命令 | 判据 |
|---|---|---|
| **日常改动** | `npm test` | 必须**全绿**。当前口径 464 例 / skip 2（2026-11-05 用户终端权威读数，含 3.7.0 轮新增 8 例判据/CLI 单测）（见下文声明性缺口） |
| **发布前** | `npm run conform` | 必须输出 `ok: true`，**并把 `digest` 与 evidence 目录记进发布说明** |

`conform`（`scripts/conform.mjs`）是 BP-3 要求的单命令门禁：`eslint` → `generate-preload --check` → `check-runtime-drift` → `check-governance-drift` → 全串测试（`--test-concurrency=1`），最后出一个随 `ok`/各步结果/源快照变化的 sha256 digest。它同时校验**跑测试期间源文件未被改动**（`sourceStable`）。

## 为什么没有做成 pre-push

有意不做，理由两条：

1. **conform 全串超过十分钟**（脚本注释自述「legitimately exceeds ten minutes」，tests 步上限 1200s）。挂在每次 push 上，会把「推送」变成一件需要等待的事，实际结果是大家开始 `--no-verify`。
2. **存在与环境相关的失败**，做成 hook 会把环境噪声变成阻塞。已实测的一批（agent 进程树内 spawn 受限 / Electron GPU 崩溃时）：

   - `real Electron copies external ASAR bodies as opaque bytes and restores them`
   - `publishes only a probed CLI version capability and binds its platform connector`
   - `real native discovery, explicit permissions, typed call, tool failure, missing reference and drift`
   - `stale host manifest is replaced by selected real interpreter snapshot, rollback is atomic and original remains`
   - `peer callable probe uses real runner prepare/claim/stop; missing business content remains pending`
   - `generic CLI body publishes only observed capabilities and uses real connector calls, update and metadata rollback`

   这 6 条在**真实用户终端是绿的**（2026-10-15 读数：9.4s / 5.6s / 30.8s / 56.0s / 16.4s / 22.0s）。遇到它们在受限环境里红，先换真实终端复跑，不要据此改产品代码。

另有一条**负载敏感**用例（2026-10-16 全量读数新增观察，非环境敏感）：`Windows fallback preserves exact Unicode/quote arguments and owns descendants on timeout`（test/task-worker-regression.test.mjs）。它与 15 分钟 electron-builder 构建并发跑完全量时 kill 超时预算被击穿而红；本树隔离复跑 4/4 绿（7.6s）。判定口诀：**先隔离复跑，绿 = 负载噪声，不要据此改产品代码**；用户终端权威读数建议一并核对。

如果日后要自动化：优先做成**手动触发的发布前检查**（`npm run conform`），而不是 push hook。

## 测试 glob 的两条硬约束（改过一次，别再踩）

1. `package.json` 与 `scripts/conform.mjs` **两处**都要限定路径，只改一处 conform 仍会红。
2. **node 24 的 `--test` 不认裸目录参数** —— `node --test test/` 会报 `Cannot find module '...\test'`，必须给 glob：`test/*.test.mjs`。

## 缺陷簿联动

重大失败走 `versions/缺陷状态簿.json`，登记后跑 `python versions/缺陷状态簿.check.py`（须 `ok: true`）。**closed 行的 `source` 必须是盘上真实存在的文件**，写人类可读读数串会被判 `ok: false`。
