# 三仓接入一键更新 0.8.1

平台页保留一个“一键更新所有平台”按钮。对象是已有有效配置的平台；配置更新、能力地板、厂商原生工具回执分别显示，模板不自动算作完整接入。

点击后先核对有效上下文窗口及来源。缺少时在同一面板补填，再点击按钮重新预览。用户确认的运行预算可作为来源；模型名称不明确或未指定平台对应关系时，不猜厂商容量。现有较小预算可继续保留。

已存在的旧位置 bridge 副本按实际配置引用确定权威来源，并与标准 bridge 一起进入备份、切换和恢复。无法确定来源时待补。个人合法字段及固定版本在预览中可核对。

资源环境复用要求所属平台、恢复证明路径、sha256、通过字段与实际安装包版本均相符；旧版合法恢复证明可沿用。恢复证明同路径变更会影响依赖该环境的检查指纹。

更新激活后检查异常或取消时，管理台先把仍属本次的配置入库为待补；无法入库时恢复自己拥有的字节。外部新改保留并提示核对。停止后可继续；跨平台先后写到的治理文件按变化链恢复。配置成功不替代原生厂商工具调用成功。

验证待补请查看各平台记录。原生模型挑战仍在原有客户端入口逐次确认，不由全局更新自动消耗模型额度。
