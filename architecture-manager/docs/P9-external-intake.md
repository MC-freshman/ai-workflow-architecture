# P9 外部来源识别

“导入本体”从现有文件、文件夹或普通 ZIP 开始，不要求先放成三仓结构。可选择 agent、skill、tool、platform、software，显示来源摘要、入口、转换清单、排除原因、占用及恢复演练峰值。列表每页 50 条，文本预览有长度上限，原文不修改。

共同域模块 src/domains/intake 包含路径、ZIP、文件策略、识别解释与来源扫描。后台 Worker 逐块读取/哈希，有字节进度和协作取消；所有来源说明只作为内容，未执行其中的指令。UTF-8/BOM 支持；不能确定的编码明确要求转换，不猜测。加密 ZIP、ZIP64 或不能确定的 ZIP 文件名编码，提示先在本机解密/解压为普通目录再选择。

共享正文仅取可冻结文本与源码。node_modules、venv、缓存和生成目录默认排除；凭据文件列出排除原因；正文凭据字面值不出现在预览或共享候选。目录联接/符号链接、ZIP 穿越、路径别名/重复、文件目录碰撞、损坏内容拒绝。普通 ZIP 校验中央/本地目录一致、实际解压长度及 CRC/SHA，未解压到用户目录。

当前只是 P9 来源预览，尚未发布、安置或启动。P10 接共同 journal/事务，P11–P15 接各类转换与验证。来源被修改后原预览失效，必须重新识别；本体、环境、凭据和证据仍归所属平台 runtime。
