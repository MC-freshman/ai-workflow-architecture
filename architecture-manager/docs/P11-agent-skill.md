# P11 专家与技能本体接入

选择「导入本体」→专家或技能→文件／目录／ZIP→入口正文。随后填写资源 ID、显示名称、新版本和职责；专家选择一条已发布主工作流。依赖通过勾选精确版本生成，不用手写 manifest、锁或 catalog。

正文读的是完整内容，超过来源预览的 32 KiB 也可编辑。原件按原始字节保留在新版本 original/；专家的 body.md 保存可编辑正文，prompt.md 是交给现有引擎的正文与所选技能上下文。技能上下文带版本、封条和正文 SHA，并在发布校验时与精确依赖比较。旧版永不覆盖。

资源页「查看全部」可编辑专家；技能目录的「读取正文」后可编辑单个技能。更新既有多技能 catalog 时只改目标技能的版本，其它条目不变，不另建重复登记。专家详情的最小调用检查只做 prepare→next→stop，不执行任务或提交结果；新导入专家还会回读领取事务，确认正文和技能进入实际提示词。

接入计划与失败续接沿用 P10 的 journal/checkpoint/CAS。登记基线未提交时请先在 Git 页提交，再继续；发布文件和指针变化也需要在 Git 页入库。状态显示的是本次操作读回，不替代平台能力地板或完整业务结果。

P11 私有样例仅放在 Codex 维护区的独立工作区，复用当前 Codex 已有能力声明做提示词链路实测，未给新平台复制接入结论。先前隔离夹具漏能力配置、以及「技能入锁但未交付」读数都保留；最终回执确认导入专家 1.0.2 已领取正文及技能，终态 stopped，业务阶段未执行。GUI 成套验证按 P17 进行，0.4.2 已发布 EXE 不含这些开发新增功能。
