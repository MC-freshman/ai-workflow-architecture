# P5 后台任务与恢复

长任务通过统一 IPC 声明进入 Node Worker；主窗口负责显示带 jobId、工作区会话标识的进度。任务结束必发送 settled，旧工作区的消息不会改变当前界面。

自有命令由平台登记的 Python Job Object 控制；未配置 Python 的 Windows 仓库克隆使用随包的 PowerShell Job Object 控制器。参数由 JSON 传入，不拼成脚本。停止请求只清理本轮子进程树。Git 提交、分支、标签和 revert 先完成当前事务；若停止到达时已经写完，界面明确提示保留结果、后续步骤尚未执行。软件 provider 接管的持久 GUI 会话不由普通任务停止按钮终止。

文档构建使用 Electron 的 Node 模式，写入站点派生输入、data 摘要、同步图片、构建缓存和 build；治理原文只读。软件健康检查读取用户所选平台的本体绑定、解释器和连接器；READY 仅代表具备派发条件，不表示功能已执行。

恢复前比较原文与本事务写入的 SHA；第三方新改保留并报告冲突。克隆在私有临时目录验证后才发布到所选工作区，失败不删除用户在目的地新加的内容。
