# 0.8.3 源码开发与核对

管理台使用 Electron/React/Node IPC，辅助平台接入与验证使用已锁定 Python 运行工具。开发 Node.js 24+，进入 architecture-manager 后执行 `npm ci`、`npm start`；构建为 `npm run package:win`。普通使用者直接运行 EXE。

`npm run conform -- --out <自己的平台检查目录>` 是应用开发检查；共享 platform-conformance 的 conform 核对三仓能力在某个平台的兑现，两者不要混淆。新增低影响资源复用现有 profile 时用受影响单格检查；首次平台接入和引擎/契约大版本变化按规定完整矩阵。保留失败和未测结果，零行不能报绿。

本次发布代码来自已验证的 0.8.3 源包，228 个 src 文件与包内内容回读一致。本轮相关回归 35 项、checker 11 项通过。全量开发检查仍有既有缺陷簿标识失败和 600 秒超时记录，没有报告全量通过。README 修改没有改变运行代码或重新发明接入判据。

资源新版本要创建新语义化目录并双向复算 SHA256SUMS，旧版不可覆盖。修改应用源码、平台配置或资源后，检查和回执要绑定当前内容，不能复用不同配置的认证结论。测试与运行产物留在个人平台 runtime，不加入共享版本。

公共导出只复制审查后的文本源码与配方，不引入私有历史、平台配置、凭据、环境和本体。推送前扫描凭据/本体/大文件，正常推送，不强推；自己的配置推荐保存到自己的私有远端。
