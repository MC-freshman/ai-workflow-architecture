# 0.8.3 快速开始

你需要一台 Windows x64 电脑、自己的 AI 客户端与账号、三仓工作区，以及按实际动作要求准备的 Git/Python/隔离环境和软件。运行管理台 EXE 无需安装开发用 Node/npm；运行工作流所需环境另算。

1. 下载 v0.8.3 便携或安装包，按 SHA256SUMS-0.8.3.txt 复算下载 SHA-256。
2. 获取 v0.8.3 源码工作区；选择包含 AGENTS.md、tool、agent、software 的根目录。可执行 `python -B scripts/verify-checksums.py` 核对发行工作树。
3. 打开管理台，等只读扫描；确认能看到三仓资源。公开快照没有作者的平台目录，这不是缺文件。
4. 在“平台与接入”创建/选择自己的平台，登记真实程序、解释器、窗口来源、环境及所需软件，预览后执行基本接入。
5. 自行完成登录、UAC、许可证、厂商确认，在客户端加载这个项目的工具入口。用真实工具返回确认它已接通。
6. 用本平台配置最小验证目标资源 prepare→领取→stop；再按所需能力运行具体任务。配置保存与业务成功分别报告。

有 wf/wfa 映射时可请求 `$wfa software-engineer 草稿：分析这一处缺陷`，专家遵循内部精确锁。没有映射时采用已经接通的 MCP/CLI，不把聊天文字当调用记录。

已有有效配置的平台可以点“一键更新所有平台”，一次核对统一预览后执行；需要收口到自己的远端时选正常推送。完整接入仍要求三仓能力并集在本平台没有缺项、未验证项，且规定认证与当前原生回执成立。

主 README 第 5–7 节已完整解释“能调用”“完整接入”和“适合让 AI 接着搭建”的条件，不必先跳转其他文档才能理解。不要用源码 ZIP 覆盖生产工作区，也不要把个人 runtime/凭据推送到公开上游。
