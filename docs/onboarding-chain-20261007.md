# 管理台 0.5.6 接入链路修复方案

2026-10-07。依据用户本次“请修复”及既有 Codex 全权维护授权执行。源码基线 95d48d8（0.5.5，已有成功 peer 分支 claimReached 补丁）；根仓基线 266b3511。本轮新增 0.5.6，不覆盖旧发行、共享释放版、旧接入日志或其它会话的未提交配置。

## 核实与设计

1. **D-105 表单保护**：当前生效配置负责初次回填；未执行计划只恢复明确的暂缓等操作选择，不用旧 fields/bodies 覆盖生效配置。按工作区/平台与请求身份拒绝迟到回读，按字段编辑状态保护扫描期间的 Python、软件路径、解释器与 WSL 选择。显式重新读取可覆盖，普通刷新不可覆盖未保存输入。
2. **peer 判据与副本更新**：95d48d8 已补成功分支字段，但旧平台副本不随源码或 EXE 自动改变。提供可预览的接入组件更新，一键续接识别模板 SHA 差异，仅更新本平台管理台登记副本并失效受影响结果。维护探针使用独立的 prepare→真实 claim→确认 stop 路径，不消费/编造业务正文；拒绝、超时、claim/stop 失败一律不通过。业务运行结果与协议可调用性分开。不能把“缺作者正文”称已跑完业务，也不能凭一个布尔键给真正失败放行。
3. **宿主环境清单**：hostEnvironmentManifest 的作用是 runner 宿主解释器校验，并非只有 host-controlled 档才相关。已有该键时，解释器/环境激活变更必须提供新宿主的实际快照或明确的可预览迁移；不盲目删除旧清单，不改在途锁。新清单写所属平台 runtime、原件保留。
4. **网关与绑定**：统一通过本平台 config.softwareGatewayConfig 解析当前配置，保留旧文件名、bodies、aliases、MCP 和凭据引用。既有旧/新文件的迁移先显示来源/差异，冲突不得静默覆盖。安置只证明备份/恢复；增加“绑定到现行配方”路径，并明确下一步。已有“发布新配方并绑定”功能保留，不冒充原来不存在。
5. **正式回读与历史隐私**：privateBytesExcluded 出自临时自制回读 JSON，并非管理台已有判据。BP-6 §6.3 明确 runtime 运行产物不入库，不能把旧入库文本一概说成合规。正式只读回读分别显示本轮配置提交/新增私有件排除、现存历史 runtime 入库问题与功能接入证据；历史问题保留数量/列表/分类，不能靠删历史或篡改旧 digest 刷绿。dsh 旧 peer 记录如实标为协议 claim/待业务输入，业务完成未验证。

不代跑六个平台全矩阵，不替各平台生产改 pin、补业务正文或删日志。验证在 Codex 私有隔离工作区进行；其它平台本轮只读核实，使用新管理台各自确认组件更新并出证。环境归属仍为 BP-1 第③路。证据目录：codex/runtime/maintenance/20261007-onboarding-chain/，agent/workflow=null。

## 有序 P 表

每 P 预算 2–3 小时（三个子块，非最低耗时）；每个子块结束都有落盘报告与无在途操作的中断点。新增检查只抓这次已实测失败，局部变化增量验证，并收敛到既有 conform。

| P | 前置 | 子块 | 产物/安全中断点 | 原定判据 |
|---|---|---|---|---|
| P1 来源核实、登记与回滚 | 用户修复指令 | ① 核对源码/包/平台副本与 81 行缺陷簿；② 核实六条并登记，保留旧结论来源；③ 两仓提交回滚锚点 | 审计摘要、P 表入库后可停 | 分清协议/业务、安置/绑定、临时回读/管理台；不把错归因写成真缺陷，改动前可回滚 |
| P2 表单与迟到响应 | P1 | ① 字段编辑状态与当前配置回填；② 请求/对象隔离及显式回读；③ 真 UI 扫描/切换回归 | 表单模块、测试、页面记录 | 刷新不回退 Python/bodies/WSL；初次回填当前配置；旧对象/旧请求不覆盖当前对象 |
| P3 网关与软件衔接 | P2 | ① 统一实际网关路径与迁移冲突；② 安置后绑定现行配方及提示；③ 保留六绑定/MCP/别名、回滚与差异回读 | 可审计计划、只读原件、绑定测试 | 旧文件名不丢绑定；不静默清空；可不发新配方绑定已恢复本体；未知/未测状态不亮绿 |

| P6 新包、文档与交付 | P5 | ① 0.5.6 双包与真实 EXE；② 安装副本与包内载荷逐 SHA、使用说明；③ 扫描、普通提交推送、四读数 | 新双包/哈希/指南，提交后可停 | 旧包不覆盖；新 GUI 可保护草稿与更新组件/绑定；HEAD/本轮 status/远端一致/回滚先于改动可回读 |

执行期其它非阻断发现只登记，不顺手重构或清理。P1–P6 满足上述原定判据即完成本次管理台修复；不等同于宣布所有平台生产重新认证完成。
