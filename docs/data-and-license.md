# 数据、反馈与许可

## 数据归属

管理台在本机工作，使用者选择自己的工作区。资源定义可以共享；平台配置、软件本体、解释器环境、运行锁、审计、缓存、日志、备份和凭据由各使用者分别管理。

本仓不提供作者的接入配置、个人目录或运行证据。首次使用需创建自己的平台，并根据自己的实际环境验证能力。个人 Git 提交与推送使用自己的仓库和真实远端。

凭据使用平台本地引用和系统凭据设施；不要写入提示词、配方、公开截图或 Git。含凭据的本地加密备份仍应按私人数据保管；换 Windows 用户或电脑时可能需要重新登录。

## 反馈问题

在仓库 Issues 提供管理台版本、操作步骤、预期与实际结果，以及已去除私人信息的错误摘要。平台名称、资源 ID 和版本号有助于复现。不要提交整个 runtime、备份目录、登录信息或访问令牌。
