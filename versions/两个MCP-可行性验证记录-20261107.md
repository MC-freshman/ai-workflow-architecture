## R1 修正 → P 表 v1.2

两份 P 表各追加 v1.2 修订段，覆盖以下条款：

1. **配方结构全字段化**：manifest 的 capability 10 字段、concurrency 4 字段、recipe 的 `verify` 3 字段一律按 `repo-lint 0.7.0` schema 填齐；P3 增加「生成后先跑 `jsonschema` 三件套再跑 `software_lint`」的子步。
2. **零绝对路径**：`install.location` 用 `${platformRuntime}/software/<id>`；server 只从环境变量 `ARCH_WORKSPACE_ROOT` / `NOVEL_PROJECT_ROOT` 取根路径；README 示例用占位符，不写 `E:\...`。
3. **Node 口径**：配方声明 `runtime: node>=20`（零依赖 stdio，R1 已在 `v22.22.2` 实测握手通过）；管理台产品自身 `>=24` 不适用于自包含配方，且**不 import 管理台源码**。
4. **工具面去子进程化**：管理台第 7 个 tool 由 `arch.relayout.dryrun`（需 spawn `node cli.mjs`，会话内对 `.exe` 有既有 EBUSY 风险）改为纯只读 `arch.platform_pins`（读七台 `bridge.json` 的 `runtimeComponentVersion`）。
5. **凭据脱敏**：`novel.project.info` 只回白名单字段与顶层键名，不回显 config 中可能的模型服务配置；JSON 内不写任何 `token/password/secret` 字面值。
6. **快照与封条**：`capabilities.snapshot.json` 带 `frozen:true` 且逐 capability 对齐；`SHA256SUMS` 生成覆盖全部文件；`SOURCE.json` 必带。
