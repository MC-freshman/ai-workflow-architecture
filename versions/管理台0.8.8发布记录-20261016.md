## 构建与环境注记

- agent 沙箱内需 `unset NODE_OPTIONS`（剥离 WorkBuddy 注入的安全删除 shim）并剥离 `CODEBUDDY_*`/`SERVER__*`/`CLAUDE_*`/`WB_*`；electron 二进制用 `node_modules/electron/dist` 本地版（44.5.0），builder 仍按惯例走 mirror 下载 zip 入缓存。
- 首次构建失败根因：`ELECTRON_MIRROR=npmmirror` 被 electron-builder 26 无视（其自绘 mirror 解析），回落 GitHub 默认源在沙箱内不可达 → `Invalid URL`；改用 `ELECTRON_BUILDER_BINARIES_MIRROR` 全 URL 后成功。0.8.6 记录里的 `ELECTRON_MIRROR=npmmirror` 对构建无效（对 @electron/get 可能有效），后续轮次以本记录为准。
