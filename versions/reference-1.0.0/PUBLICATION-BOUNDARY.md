# Publication boundary

This repository is deliberately self-contained and safe to reuse as a reference implementation.

Included:

- architecture and adapter specifications;
- JSON schemas;
- dependency-free reference adapter and validator;
- original minimal Workflow and Agent examples;
- tests and CI.

Excluded:

- production Workflow, Agent, skill, and capability-pack catalogs;
- vendored or mirrored upstream source trees;
- private acceptance evidence and business runs;
- platform credentials, configuration, logs, caches, and user data;
- machine-specific absolute paths.

The architecture is public; private resource repositories can implement the same interfaces without being copied here.
