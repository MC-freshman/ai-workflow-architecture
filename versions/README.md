## 5. 命名约定（新增文件请照此写）

`<主题>-<类型>-<YYYYMMDD>.md`，类型词固定为：`P表` / `收口记录` / `发布记录` / `判据` / `台账` / `盘点` / `同步记录` / `报告`。基线文件用 `架构<semver>.md`（无日期），现行总账固定为 `更新日志.md` / `平台接入清单.md` / `缺陷状态簿.json`。
状态口径：标 **现行** 的才代表当前盘面；标「历史 / 冻结 / 提案」的按日期保留，不改写、不追认。
