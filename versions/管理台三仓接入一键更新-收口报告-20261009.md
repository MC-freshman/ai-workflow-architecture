## 用户操作与范围

在“平台与接入”点击唯一的“一键更新所有平台”，自动纳入已有有效接入配置的平台；一次确认后依次准备精确依赖、激活配对栈、核对三仓选版、运行受影响检查和 Git 入库。每个平台使用自己的配置、环境与证据，一方待补不妨碍独立平台继续。缺窗口、解释器、能力、本体或原生接口时保留待补。可停止、继续和恢复旧接入配置；外部新改不覆盖。

共享 current、旧释放版和在途 run-lock 不改写。资源环境归 BP-1 §1.6③目标平台 runtime，独立于 runner 密封环境；备份按 BP-7 登记与实恢复。推送需要本次勾选，未推送为“已验证，待推送”；恢复只提交本地，正常推送另走 Git 页面。没有厂商无模型接口时不伪造原生调用结果。

本轮是管理台开发、发行与隔离测试，没有替其他生产平台执行采纳，也没有新发共享 runner/Skill/Agent。原有 qoder runtime 改动和未跟踪运行证据保留，未入本轮提交。此前专家扩充成果保持原发布形态；EXP-01～EXP-03 不在本轮实施范围。
