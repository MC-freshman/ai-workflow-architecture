## 2. 布局修复细则（对应截图问题）

1. **发布向导表单**：`.integration-form` 改 CSS Grid（`grid-template-columns: max-content minmax(220px,1fr)`），标签列固定不换行挤压；下拉与输入框定宽；"发布"与"标记 deprecated"两个功能区用小节标题分隔，不再共享一行布局。
2. **单视图全宽**：页签激活时该视图面板单列全宽（max-width 1280px 居中），废除现在的两栏 grid 挤压；左右留白由容器吸收。
3. **长列表改内部滚轮**：runs（222 条）、审计、inbox、文档列表容器 `max-height: 60vh; overflow-y: auto`——滚轮在列表内，不再撑长整页。
4. **页签栏**：topbar 下方一条 Burp 式横向页签（激活态高亮），替代现在的 nav-chips 吸顶条。
