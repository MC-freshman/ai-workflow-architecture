## 已确认问题与处理选择

1. 当前软件网关文件与遗留文件每次强制合并，已合法更新的 `.py` 被旧路径阻断。当前配置显式指针是唯一运行权威；遗留差异只展示，不参与普通读写。恢复缺少项必须单独预览迁移，冲突来源可明确选择，原文件保留。
2. 软件路径留空会被过滤，保存只做追加，不能解除绑定。空值表示明确解除该项绑定；不删除软件本体，认证仍如实显示缺口。
3. 显式重新读取未重置隔离环境字段。统一重置全部配置草稿、能力回执与环境检测结果；后台重扫保留编辑。
4. 核对后续跑失效了环境步骤，却仍复用旧安装计划。失效步骤包含 environment 时封存旧计划并清除在用计划，重新准备环境；strict 仍拒绝未核对漂移。
5. 部分文件选择回调未处理对象切换异常，部分本体表单的请求上下文不含选中对象。统一捕获过时结果并禁止旧请求改写新对象。
6. 平台私有路径采用字符串截取而非路径归属校验；软件声明路径未逐层校验链接。共用路径函数，按所选工作区解析相对路径，拒绝跨平台、根外、链接越界。

“全面排查”包括既有认证、接入、平台、tool/agent/skill、软件、Git、审计/回滚的源码入口与既有测试回归；不承诺所有未来缺陷均不存在。D-112 历史 runtime 入库治理另案，禁止以删除历史或强推绕过。
