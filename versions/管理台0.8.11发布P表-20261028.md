## P2 构建 0.8.11 发行包（约 15–25 分钟）

- 子块 ① `node scripts/collect-seed.mjs` + `npm run build:ui`（generate:preload → build:bridge → lint → vite build）
- 子块 ② `electron-builder --win nsis portable --publish never`
- 判据：`release/out-0.8.11/` 生成 `Architecture-Manager-0.8.11-setup-x64.exe` 与 `-portable-x64.exe`，EXIT 0
- 环境变量（0.8.8 先例）：剥 `CODEBUDDY_*`/`SERVER__*`/`CLAUDE_*`/`WB_*`；`unset NODE_OPTIONS`；`ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`（electron-builder 26 **不读** `ELECTRON_MIRROR`）
- **已知风险**：agent 进程树内 spawn `.exe` 可能全 EBUSY（Electron 打包的既有环境限制）。**失败即停手交用户终端命令**，不反复重试、不产半截发布
- 停手点：构建失败时 `release/` 不新增可发布资产，工作树保持干净
