## 5. 风险登记与不解决

1. electron-builder 长任务在会话内可能超时/GPU 异常 ⇒ 后台执行、失败即登记（历史 `发布门禁.md:19-28`、`0.8.14:21`）。
2. 自签证书不受信任（`UnknownError`）属预期，判据只认签名存在 + RFC3161 时间戳。
3. `app.asar` 锁 ⇒ 输出走 `release-0900`；残留壳需重启 WorkBuddy 后清，不强删。
4. P2/P3 改 sources ⇒ 权威 digest 必然失效，须 P7。
5. 公开仓同步、`docs-site` 改版、平台逐台出证、D-175 等 §10 项**不解决**，需另立 P 表。
