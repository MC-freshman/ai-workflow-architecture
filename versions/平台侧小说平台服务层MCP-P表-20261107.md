## 5. 风险登记

1. 服务层是**仓外源码**，版本会随小说平台升级漂移 ⇒ 配方不冻结它，MCP 只做运行时注入，并在 README 写明「与 0.3.9 服务层签名绑定，升级后需复跑 P4」。
2. 服务层写函数内部有并发队列与事务（`enqueueChapterSave` / `withProjectTransaction`），MCP 单进程串行调用，不与运行中的 Electron 应用并发写同一项目；README 明写**同时打开应用时禁止写工具**。
3. `searchRelevantChunks` 在未建索引时返回空属正常（探针读数 `chunks: []`），不是能力缺失，工具须如实返回 `indexed:false`。
4. 平台私有件被 `.gitignore` 排除，**恢复演练是唯一有效性证明**，不得跳过。
5. 本轮不改共享配方 1.0.0；若要让其他平台也用上服务层，须另立 P 表处理 BP-2 与 `declaredAbsent`。
