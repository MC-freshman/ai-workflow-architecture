## 构建与签名

- `npm run package:win`（electron-builder 26.15.3 / electron 44.5.0）**EXIT 0**，耗时约 15 分钟。环境变量：剥 `CODEBUDDY_*`/`SERVER__*`/`CLAUDE_*`/`WB_*`、`unset NODE_OPTIONS`、`ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`。
- **签名**：electron-builder 日志里的 "signing with signtool.exe" 是无条件打印、未配置证书时静默跳过的（实测两包 `Get-AuthenticodeSignature.Status=NotSigned`）。按 0.8.6/0.8.8 先例手工补签：`C:\Program Files (x86)\Microsoft SDKs\ClickOnce\SignTool\signtool.exe`，`/fd sha256 /sha1 FD54720C66F98EE14D73A156AAC8839585FDD025 /tr http://timestamp.digicert.com /td sha256`，双包 `Successfully signed`。
- 补签后签名者（CN=42a636a1-5781-4297-9fd5-278b040e8893，2027-09-20 到期）与 DigiCert RFC3161 时间戳均在；`Status=UnknownError` 是自签名根不在默认信任库的预期现象（SmartScreen 提示，不代表文件被改动），以 SHA-256 核对为准。
