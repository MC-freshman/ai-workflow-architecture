# 平台调用接口入口

管理台 0.8.1 连接使用者自己的客户端。共享侧负责资源解析、契约、版本和配方；每个平台声明其真实接口、环境与能力。

prepare 固定资源及依赖并创建版本锁；next 根据当前锁与状态领取或提交阶段；stop 记录停止终态。使用者平台须分别核对可调用性、真实脚本/模型入口和能力地板，不由目录存在推定。

最新的完整机读契约与 schema 在 tool/runtime-contracts，流程引擎在 tool/wf-runner。选择对应 versions 目录中的定义，服从运行锁；应用 0.8.1 不替代引擎/契约版本。

未写档位按草稿范围；过图与交稿按流程声明执行。管理台界面步骤见 docs/user-guide.md。
