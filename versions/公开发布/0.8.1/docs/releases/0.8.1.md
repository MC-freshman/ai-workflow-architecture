## 本版更新

- 一键更新平台前，先核对有效上下文窗口及来源；缺失信息可在当前面板补填后重新预览。
- 旧位置的 bridge 副本按配置引用确定权威来源，与标准副本一起备份、配对切换并恢复。
- 环境恢复证明根据所属平台、路径、摘要、通过字段和实际安装版本核对；有效的旧证明可以复用。
- 更新激活后遇到异常或取消，按本次变更归属保存待补配置；无法入库时恢复自己的字节，保留外部修改。
- 改善停止后继续、跨平台先后变更的恢复链，以及导入面板默认归属。

## 升级

退出旧管理台，启动本版并选择原有个人工作区。不要用源码 ZIP 覆盖个人配置。资源或平台接入更新仍先预览，再确认执行；详细步骤见 [快速开始](../quick-start.md#5-从旧版升级)。

## 适用范围与已知边界

配置更新、能力地板、客户端回环和厂商原生工具回执分别显示。没有厂商接口的 GUI 程序可以登记和启动，内部业务仍由用户或其接口完成。登录、UAC 和系统安装交互由对应厂商或系统界面处理。

现有 MCP 接入支持 stdio、SSE 和 Streamable HTTP；OAuth、特殊证书、专用传输及不支持的协议版本按待适配显示。所需软件和平台环境必须在用户自己的工作区准备。

既有 0.8.1 验证记录包含 276 项检查：274 通过、0 失败、2 项按环境条件跳过；便携 EXE 的更新、停止、继续和恢复链曾在隔离工作区实测。本次核对双包内嵌版本、ASAR 与 225 件来源文件，并逐件验证发布附件；没有替使用者宣布厂商接入或生产安装已完成。
