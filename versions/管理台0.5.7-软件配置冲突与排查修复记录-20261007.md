## 结论与现网原因

zcode 的 runner config 已指向 `bridge/software-gateway-config.json`，`.py` 已是平台自己的 manager-environments/host 解释器，6 件 bodies 齐全。旧 `software-gateway.json` 仍登记旧 py-env 解释器。0.5.6 每次合并两份文件，导致历史路径阻断已合法更新的当前配置；不是 Python 安装损坏。

0.5.7 以显式软件配置指针为权威。旧文件只显示缺少项和差异项，需要恢复时另走明确迁移计划。当前 runner 的解释器优先于旧 bridge 中的重复值。未知唯一指针且两份配置相互冲突时，界面可读但普通保存要求先明确选择。没有删除、覆盖或手工修改 zcode 的原件来消除错误。
