## 3. 回滚与不迁入 inbox 的代价

- 本次**不建立 `inbox` 副本**。回滚唯一依赖根仓 git 历史：删除前最后一个提交即回滚锚点；
- 回滚必须用 **raw blob**，不能用 `git checkout` / `git archive`：后两者会应用 EOL 过滤器，实测对 1.7.2 的 4 个文本文件产生 CRLF，与 `SHA256SUMS` 不符；
- 逐文件回滚示例：`git cat-file blob <删除前HEAD>:<repo-relative-path> > <目标路径>`；
- 删除前已用 raw blob 对 `tool/math-modeling-programmer/versions/1.7.2` 做一次恢复演练（1,141/1,141 文件、`SHA256SUMS` 1,140 条全过、0 hash mismatch，证据在 run 的 `work/verification/git-restore-result.json`）；
