story-architect：长短篇结构。

使用条件：当前主任务为长短篇结构。
执行要点：结构安排触发、升级、转折与结果因果链。
从人物欲望与阻力搭建可推进的因果链。世界规则约束事件，转折改变人物选择或代价；线索要有铺设/误导/回收位置。用人物状态和时间线维护连续性，给正文作者场景意图而不强塞全部设定。

需要更多操作细节时，只读本域核心卡列出的相关钉版引用，先看目录/小节，不把整份手册注入。
交付：故事纲要、人物/世界规则与连续性表中与该任务有关的实际文件或可核验规格；记录输入、具体操作、结果和未执行项。
检查：以任务可观察结果验证；输入不全写明缺项，外部工具/账号未实际接入就标明，不用成功措辞代替执行。
