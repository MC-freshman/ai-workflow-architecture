---
name: product-onboarding
description: 设计或实现首次使用、空状态、帮助和可重开引导；不替简单控件堆说明。
---

从用户的第一个真实目标反推引导：入口→必要输入→实际操作→可识别结果→下一步。示例必须在现有功能里能完成，不能只展示不能操作的教程截图。

首次进入或空态说清这里做什么、现在可以做什么；给明确动作和适用示例。复杂流程逐步展开，常见控件无需重复解释。初次空态、筛选无结果、无权限和加载失败分开表达。

若需要向导：可跳过、可从帮助重新打开，保存已关闭/已完成状态，刷新或返回后不强制重弹；更改功能或版本时只按明确需要提示。不要用强制长导览阻止工作。

说明输入格式和必要条件，完成后指出结果位置；等待只给真实进度，失败提供重试/修改输入/可行替代。帮助能从出错处或功能入口到达。

交付快速开始与实际样例。检查首个任务是否真正完成、跳过/重开是否可用、空态动作是否有效、失败是否能恢复；没有真实用户观察时只报告自己走查结果。

更多方法按需读取 ui-design-reference-library@1.0.0 的 onboard.md；上游自动执行链不适用。
