---
name: interface-visual-review
description: 实际渲染与走查界面，对照视觉规则检查状态、长文案和操作；不以静态检测冒充美观。
---

先确定本次范围、已选视觉规则、实际支持的设备/窗口和可操作任务。旧界面小修保留既有身份与行为，不借检查改成另一种设计。

完成后一次集中检查：按目标平台采集代表性宽/紧凑尺寸的真实渲染；走首个真实任务、帮助/重开、空态、失败恢复、加载/成功和键盘路径；检查长中文文案、标签、按钮、对齐、遮挡、焦点和对比度。只检查当前功能会出现的状态。

结合截图和实际操作判断层次、密度、字体与组件是否符合设计说明。静态检测没有报错、DOM存在或截图文件存在，都不能单独证明界面好看或可用。

集中修复本次看到的实际缺陷，最多再做一次集中确认；不反复扫描或无限打磨。超出本次范围的非阻断问题登记。小改用已有必要证据，不强制完整截图矩阵。

交付截图身份、尺寸、操作/状态结果、检查范围与未执行项。无法运行或没有原生设备时明确待验证，不把网页样例称为原生应用实测；未做真实用户测试就不宣称成功率。档位遵循调用请求，未交稿不称冻结。

复杂细节按需读 ui-design-reference-library@1.0.0 的 polish.md；不调用上游自动启动器或hooks。
