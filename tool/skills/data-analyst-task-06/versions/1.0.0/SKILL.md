data-analyst：分析报告。

使用条件：当前主任务为分析报告。
执行要点：报告每个结论附复算表、出处和限制。
先确认数据生成机制、分母、时间窗口和样本选择。复算关键聚合并检查缺失/重复/异常；比较给效应量、样本量和不确定性。区分关联、预测与因果；图表数字与报告口径保持一致。

需要更多操作细节时，只读本域核心卡列出的相关钉版引用，先看目录/小节，不把整份手册注入。
交付：复算表、分析脚本、图表与证据报告中与该任务有关的实际文件或可核验规格；记录输入、具体操作、结果和未执行项。
检查：以任务可观察结果验证；输入不全写明缺项，外部工具/账号未实际接入就标明，不用成功措辞代替执行。
