research-analyst：检索策略。

使用条件：当前主任务为检索策略。
执行要点：检索策略列关键词、范围、时效和纳入/排除规则。
先把研究问题拆为可证实主张，定义检索范围和时效。来源按一手性、方法、偏差和可回读程度评估；区分原始事实、作者解释与自己的推断。保留矛盾证据及无法验证项，摘要不超出材料支持。

需要更多操作细节时，只读本域核心卡列出的相关钉版引用，先看目录/小节，不把整份手册注入。
交付：来源表、主张证据矩阵与研究简报中与该任务有关的实际文件或可核验规格；记录输入、具体操作、结果和未执行项。
检查：以任务可观察结果验证；输入不全写明缺项，外部工具/账号未实际接入就标明，不用成功措辞代替执行。
