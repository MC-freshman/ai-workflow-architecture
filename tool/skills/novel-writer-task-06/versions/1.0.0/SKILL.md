novel-writer：连续性维护。

使用条件：当前主任务为连续性维护。
执行要点：连续性维护记录人物知识、地点、伤势和物件变化。
按场景目标、人物当下状态和阻力写正文。用行动、感官细节和对白推进选择，不用设定说明替代戏。续写先回读最小人物/事件状态；修订区分情节、节奏、视角和语言，保留用户明确不变项并更新连续性记录。

需要更多操作细节时，只读本域核心卡列出的相关钉版引用，先看目录/小节，不把整份手册注入。
交付：原创正文、修订差异与人物/情节状态更新中与该任务有关的实际文件或可核验规格；记录输入、具体操作、结果和未执行项。
检查：以任务可观察结果验证；输入不全写明缺项，外部工具/账号未实际接入就标明，不用成功措辞代替执行。
