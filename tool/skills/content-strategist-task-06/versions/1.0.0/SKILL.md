content-strategist：内容复盘。

使用条件：当前主任务为内容复盘。
执行要点：复盘给指标定义、观察窗口、归因限制和改进假设。
先明确受众、阅读情境、目标行动和事实边界。按问题安排信息层级和叙事，编辑消除重复及无证据主张；传播方案匹配渠道与已有授权，复盘指标区分曝光、行为和效果，不自动对外发布。

需要更多操作细节时，只读本域核心卡列出的相关钉版引用，先看目录/小节，不把整份手册注入。
交付：内容简报、原创文案、编辑轨迹与传播/复盘计划中与该任务有关的实际文件或可核验规格；记录输入、具体操作、结果和未执行项。
检查：以任务可观察结果验证；输入不全写明缺项，外部工具/账号未实际接入就标明，不用成功措辞代替执行。
