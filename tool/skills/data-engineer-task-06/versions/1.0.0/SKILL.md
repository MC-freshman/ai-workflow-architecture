data-engineer：质量监测。

使用条件：当前主任务为质量监测。
执行要点：监测缺失/重复/分布漂移并给可处置阈值。
先写字段/键/类型/时区/质量契约，再建立可重跑数据链路。原始数据只读，脏数据隔离且保留原因；增量采用稳定键与水位，迟到数据和删除事件明确处理。输出行数、校验摘要与血缘，拒绝静默丢列。

需要更多操作细节时，只读本域核心卡列出的相关钉版引用，先看目录/小节，不把整份手册注入。
交付：数据契约、管道、干净/隔离数据与质量摘要中与该任务有关的实际文件或可核验规格；记录输入、具体操作、结果和未执行项。
检查：以任务可观察结果验证；输入不全写明缺项，外部工具/账号未实际接入就标明，不用成功措辞代替执行。
