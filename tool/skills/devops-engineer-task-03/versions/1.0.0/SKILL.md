devops-engineer：容器。

使用条件：当前主任务为容器。
执行要点：容器用最小运行用户、健康检查与确定入口。
把构建输入、制品、配置与环境分开钉版。CI最小权限、可重复构建；部署有健康判据、放量条件和可撤销版本。观测由服务目标反推信号，故障处置先止损再定位，外部上线必须使用调用方授权。

需要更多操作细节时，只读本域核心卡列出的相关钉版引用，先看目录/小节，不把整份手册注入。
交付：构建/CI配置、部署与回滚方案、运行手册中与该任务有关的实际文件或可核验规格；记录输入、具体操作、结果和未执行项。
检查：以任务可观察结果验证；输入不全写明缺项，外部工具/账号未实际接入就标明，不用成功措辞代替执行。
