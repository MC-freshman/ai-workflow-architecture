database-engineer：索引。

使用条件：当前主任务为索引。
执行要点：用EXPLAIN和基数评估索引收益及写入代价。
从数据不变量设计约束、键和事务边界。索引用执行计划及读写成本决定；迁移先在副本验证锁、数据转换和回滚。恢复不仅有备份文件，还要读回恢复的数据与关键约束。生产动作服从明确范围和授权。

需要更多操作细节时，只读本域核心卡列出的相关钉版引用，先看目录/小节，不把整份手册注入。
交付：DDL/SQL、计划读数、迁移和恢复证据中与该任务有关的实际文件或可核验规格；记录输入、具体操作、结果和未执行项。
检查：以任务可观察结果验证；输入不全写明缺项，外部工具/账号未实际接入就标明，不用成功措辞代替执行。
