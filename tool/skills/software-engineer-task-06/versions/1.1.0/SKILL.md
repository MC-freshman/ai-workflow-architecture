description: 软件交付：可启动入口、真实快速开始、运行证据及恢复说明。
---

对照本次交付范围，读回实现、真实运行/检查证据、未执行项，以及迁移影响和撤销方式。
新软件给启动入口、首个真实任务、可用输入示例、预期结果和结果位置、常见错误恢复；CLI 给帮助/命令及退出错误，API 给请求/响应。仅点名局部修改时补相应说明，不追加完整手册。
有界面时读回相邻主责的设计规则、实际界面/引导与必要操作证据；缺失项明确留待办。快速开始必须与当前功能和真实操作一致，不能提供还没实现的功能说明。
交付变更、实际检查、使用入口与说明路径、风险与恢复、待办。缺省草稿；没有实际执行不称已验证，没有交稿不称冻结。
