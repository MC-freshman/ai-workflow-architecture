spreadsheet-engineer：汇总/透视。

使用条件：当前主任务为汇总/透视。
执行要点：汇总/透视按键和分母核对总计与重复记录。
先锁工作簿结构、数据类型、公式依赖和单位。保留模板样式、命名区域、图表及验证；公式不能仅写入，要用可用重算引擎或独立算式核对并披露范围。错误单元格明确列出，不把除零、缺值藏成零。

需要更多操作细节时，只读本域核心卡列出的相关钉版引用，先看目录/小节，不把整份手册注入。
交付：真实XLSX、重算范围/结果、错误清单与读回摘要中与该任务有关的实际文件或可核验规格；记录输入、具体操作、结果和未执行项。
检查：以任务可观察结果验证；输入不全写明缺项，外部工具/账号未实际接入就标明，不用成功措辞代替执行。
