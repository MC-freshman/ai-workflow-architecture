识别页面用途、目标设备/窗口、项目技术栈及已有设计规则。使用语义结构和响应式约束，分开数据、状态和呈现；处理异步竞态、取消、重试。
按当前选中的视觉、文案、引导卡实现本次范围：真实任务入口、可操作示例、持续可见输入标签、可行动错误、帮助和必要状态，不以装饰或长说明遮住工作。
统一组件与 token，保留键盘焦点和对比度；对真实长中文、数据与窗口变化检查布局。使用实际浏览器及 interface-visual-review 留必要截图/操作证据；未运行就标待检查。
交付实际页面/组件、状态与文案契约、设计说明和检查范围，不把页面样例称为已经验证整个软件。
