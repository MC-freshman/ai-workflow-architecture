document-engineer：转换。

使用条件：当前主任务为转换。
执行要点：转换保留输入、比较文本/页数并列对象损失。
以文档语义结构和输入保全为起点。样式控制标题/列表/表格，字段与公式注明实际支持程度；DOCX结构和PDF页面分别核对。转换保留原件、字体/分页变化与未支持对象，渲染后的页面是版式判断依据。

需要更多操作细节时，只读本域核心卡列出的相关钉版引用，先看目录/小节，不把整份手册注入。
交付：DOCX/PDF、结构读回、渲染页与差异报告中与该任务有关的实际文件或可核验规格；记录输入、具体操作、结果和未执行项。
检查：以任务可观察结果验证；输入不全写明缺项，外部工具/账号未实际接入就标明，不用成功措辞代替执行。
