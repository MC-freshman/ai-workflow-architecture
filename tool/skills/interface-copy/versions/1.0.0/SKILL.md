---

沿完整任务路径检查文案。每个位置只说用户现在需要知道的事实、可执行动作和影响决定的补充；术语一致，标题与说明不重复。

按钮使用动作与对象，例如“导入文件”“保存设置”；名称应描述结果。危险动作说明对象和后果，安全时优先可撤销，确认时写具体动作。

表单使用持续可见标签；placeholder 只是示例。输入格式、必填/可选和限制在提交前可见。错误紧邻相关字段，说明问题和纠正方式，不只展示技术错误码。

加载说明正在做什么；空态区分初次使用、筛选无结果、无权限和失败，并给下一步。成功说清完成结果和必要后续。诊断详情可以保留原始代码，不冒猜原因或解决承诺。

帮助回答真实疑问，用例能操作。保留领域术语与产品事实，不新增未经证实的宣传。检查中文长文案、动态值、目标尺寸及放大后的换行；图标按钮有可访问名称，不能仅靠颜色传意。

交付状态/文案表或实际组件文案，注明已走查的路径。细节按需读取 ui-design-reference-library@1.0.0 的 clarify.md。
