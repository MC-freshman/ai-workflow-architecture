llm-engineer：成本/质量评估。

使用条件：当前主任务为成本/质量评估。
执行要点：固定数据比较质量、延迟、费用及漂移回退。
把生成、检索、证据和工具副作用分开设计。先固定可判定任务与数据集，再比较提示/RAG/工具方案。检索保留文档ID、段落、版本和召回证据；没有证据要弃答。工具参数验证、最小权限和幂等由宿主执行，不能信任模型自报成功。

需要更多操作细节时，只读本域核心卡列出的相关钉版引用，先看目录/小节，不把整份手册注入。

检查：以任务可观察结果验证；输入不全写明缺项，外部工具/账号未实际接入就标明，不用成功措辞代替执行。
