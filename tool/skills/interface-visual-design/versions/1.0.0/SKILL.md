name: interface-visual-design
description: 按产品与使用场景确定视觉方向、布局和设计token；用于界面任务。
---

先读用户风格、已有界面、实际产品用途、受众与运行设备，识别项目技术栈。应用工具优先任务入口、扫描效率和熟悉操作；营销展示与工具操作采用不同布局目的。

新界面或较大改版给一段视觉方向及必要token：字体/中文回退、字号层级、间距、表面/边框、品牌与状态颜色、组件密度。小修复用已有规则。配色和字体资料是候选，先判断适用性，不能从检索记录无脑复制落地页或固定框架。

组织信息层次与稳定布局：重要动作突出，相关项靠近，组间留空间，重复组件统一。正文、表格和帮助有可读字号/行距；长中文标题、数据、按钮和小窗口有明确换行/收缩策略。

颜色承载一致语义，文字/控件/焦点对比应实际检查。统一图标体系和组件状态；动效表达变化且尊重减少动画设置。用户指定的风格优先，不把某种审美写成万能禁令。

交付简短设计说明、token与组件/状态规则，并将实际界面与它对应。无品牌约束时给有理由的克制方向，不添加装饰依赖、字体下载或动画库来凑效果。视觉检查用 interface-visual-review。

复杂选择按需读取 ui-design-reference-library@1.0.0 的 operate.md 及 styles/colors/typography/products 数据相关行，单批≤4000估算token。
