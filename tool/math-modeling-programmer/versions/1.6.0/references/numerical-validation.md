# 数值验证规范

## 验证层次

1. 公式层：量纲、符号、边界和退化情形。
2. 算法层：小规模输入与手算/穷举、收敛性、停止条件。
3. 实现层：独立实现或不同求解路径、随机种子复现、输入输出契约。
4. 结论层：基线比较、参数敏感性、不确定性和失败边界。

## 必须记录

```text
check_id, target, method, expected, observed, status, evidence, impact
```

`NOT_RUN` 不是 `PASS`。如果验证失败但仍采用结果，必须解释原因、影响和补救证据。

## 常见错误

- 用样本次品率直接当真实概率，忽略抽样不确定性；
- 用一次随机模拟报告精确结论；
- 只检查优化器是否返回 `success`，不检查约束和目标值；
- 只用同一段代码验证自己，未构造独立检查；
- 通过截断坐标轴、删除异常值或隐藏误差来美化结果。
