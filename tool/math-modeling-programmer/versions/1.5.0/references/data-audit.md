# 数据审计规范

## 审计目标

在任何建模或清洗前回答：数据来自哪些文件，行和列分别代表什么，主键如何关联，
单位是否一致，缺失和异常是否改变目标指标。

## 最小检查集

```text
文件：格式、编码、表名、大小、修改时间
结构：行数、列数、列名、类型、唯一值数量
质量：空值、重复行、无穷值、异常范围、常量列
关系：主键唯一性、外键匹配率、重复匹配和孤立记录
语义：单位、方向、时间顺序、坐标系、正负号
```

## 处理原则

- 原始文件只读；清洗规则写在代码或配置中。
- 删除行、插值、截尾、标准化和单位转换都要有数量统计。
- 不确定的字段语义标为 `UNCONFIRMED`，交给建模手确认。
- 审计报告应包含样本行、范围和问题清单，但不泄露不必要的隐私。

## 推荐输出

```text
reports/data_audit.md
results/data_dictionary.csv
results/processed_data_manifest.json
```
