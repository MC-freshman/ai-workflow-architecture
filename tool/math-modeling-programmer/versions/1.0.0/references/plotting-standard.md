# 编程手图表规范

## 图表职责

每张图先写一句话结论，明确主比较对象、可能推翻结论的现象和误差定义。多面板图
应分别承担现象、模型结果、基线比较和稳健性等不同证据角色。

## 默认规则

- 数据必须来自结果文件，不手工改数字。
- 坐标轴、单位、图例和子图标签完整；可比较的子图尽量统一坐标范围。
- 同一方法跨图使用同一颜色和线型；颜色不是唯一编码。
- 误差线注明是标准差、标准误、置信区间还是数据覆盖范围。
- 普通图优先 PDF/SVG；栅格图至少 300 dpi。
- 论文实际宽度下文字仍清晰，灰度打印后仍能区分主次。

## 生成检查

检查裁切、碰撞、标签重叠、异常值、坐标截断和图注含义。图注说明“画了什么”，
正文解释“说明了什么”。
