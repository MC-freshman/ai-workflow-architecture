# Changelog

## 1.5.0

- 增加构图紧凑度门：测量坐标轴、图例、标题和图内说明的渲染边界；报告轴面积比例、外边距、
  侧栏空置率、图例方向匹配和图注间距；
- 对外置图例计算上、下、左、右候选布局的预计新增画布面积，优先建议无碰撞且更紧凑的方向；
- 严格图表 QA 将构图 WARN 视为阻断，避免仅因“没有碰撞”就交付大面积空白图；
- 新增 `composition.json` 证据文件和构图审计回归测试。

## 1.1.0

- 增加三层图表 QA：Matplotlib 预览和包围盒检查、最终 PDF 几何碰撞、PNG 视觉复核证据；
- 增加多面板最终物理尺寸对齐门和 PDF 实际字体大小检查；
- 增加 figure contract、QA 报告和视觉复核记录 schema；
- 增加 `figure_qa` 与 `record_visual_review` MCP 工具；
- 以来源快照方式纳入 Nature Skills 和数学建模 Skills，并保留迁移来源记录。

## Unreleased

- 增加任务驱动执行层：JSON 任务清单、依赖拓扑、批量运行、输入/代码指纹缓存和任务登记表。
- 增加任务人工审核脚本，并让项目初始化自动生成任务目录、示例清单和本地任务运行脚本。

## 1.0.0

- 增加项目初始化、九阶段状态机和阶段门；
- 增加输入、配置、代码和结果的哈希血缘登记；
- 实验运行器记录环境、随机种子、日志、超时和输入版本；
- 增加声明式验证插件、环境记录、结果和图表检查；
- 增加 PDF 基础完整性和 LaTeX 日志检查；
- 增加网络传播、几何覆盖、质量控制、光谱信号四类题型适配器；
- 增加 12 个行为评测场景；
- 增加项目级受限 stdio MCP Server，拒绝任意命令和越界路径；
- 增加项目自检脚本和可移植 SHA-256 交付清单。
