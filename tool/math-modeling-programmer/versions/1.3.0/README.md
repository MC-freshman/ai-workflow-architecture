# math-modeling-programmer

A programming-focused skill package for mathematical modeling competitions, upgraded to v1.1.

It covers data auditing, baseline and solver implementation, experiment tracking, numerical
validation, paper-ready figures, pattern adapters, behavior evaluation, reproducible execution,
and a restricted stdio MCP server. V1.1 adds render-time figure QA, PDF geometry/font audits,
and hash-bound visual review evidence. See `README_CN.md` for usage and stage gates.
