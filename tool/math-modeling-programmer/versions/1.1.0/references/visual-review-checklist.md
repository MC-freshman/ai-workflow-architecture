# PNG 视觉复核清单

逐项观察最终尺寸预览，不以“看起来不错”代替记录：

- [ ] 中文、负号、希腊字母、上下标没有方框或乱码；
- [ ] 标题、轴标签、图例和标注没有被裁切；
- [ ] 图例没有遮住点、线、柱或误差棒；
- [ ] 数据标注之间没有互相覆盖；
- [ ] 多面板标签横向、纵向对齐，子图之间没有侵入；
- [ ] 颜色、线型和 marker 在灰度或色盲条件下仍可区分；
- [ ] 数据点、曲线、误差棒和最高柱没有被坐标范围切断；
- [ ] 同一方法在各面板中颜色、名称、单位和不确定性定义一致。

发现问题时回到源码修改并重新渲染；不得在 PNG 上手工修图。
