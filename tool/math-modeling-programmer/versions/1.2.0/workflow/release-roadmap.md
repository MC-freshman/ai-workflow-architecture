# 版本升级路线

## V1.1：渲染与碰撞 QA 闭环

- 增加 figure contract 和 `build_figure()` 绘图入口；
- 在最终物理尺寸下生成 PNG 预览，并执行文字/刻度包围盒检查；
- 对最终 PDF 执行文字、线条、裁切和可疑填充边缘的几何审计；
- 对多面板执行 plot-area 对齐、间距和标签锚点门禁；
- 记录绑定源代码、预览和 QA 报告哈希的 PNG 视觉复核；
- 缺少 PyMuPDF 或视觉读取能力时返回 `NOT_RUN/BLOCKED`，不得伪报通过。

## V0.2：项目底座

- `init_project.py` 创建标准项目目录、项目清单和阶段状态；
- `stage_machine.py` 管理九阶段状态和门槛；
- `register_result.py` 登记结果及输入、代码、配置哈希；
- `check_lineage.py` 检查结果证据是否仍与当前文件一致。

## V0.3：实验和验证

- 实验运行器记录环境、输入、配置、种子、日志、退出码和输出文件；
- 验证插件返回统一的 `PASS/FAIL/NOT_RUN` 结构；
- `record_environment.py` 生成解释器、平台和依赖清单。

## V0.4：图表和 PDF

- 图表登记表绑定图表与结果结论；
- 图表质量检查覆盖文件类型、尺寸、DPI、标签和裁切风险；
- PDF 检查覆盖文件完整性、页数和编译日志中的溢出警告。

## V0.5：题型适配和评测

- 提供网络传播、几何覆盖、质量控制、光谱信号四类适配器；
- 适配器只提供数据契约、检查项和实现提示，不替代新题建模；
- `evals/` 保存行为测试场景和评分标准。

## V1.0：受限 MCP

- `scripts/mcp_server.py` 提供 stdio JSON-RPC 工具；
- 工具只接受项目内相对路径，只调用已登记的本地脚本；
- 禁止任意 shell、覆盖原始数据和覆盖已冻结结果；
- MCP 不可用时，所有功能仍可通过 CLI 使用。
