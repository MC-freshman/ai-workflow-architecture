# 历年案例的使用边界

案例库用于学习“问题结构—实现策略—验证方式”的对应关系，不用于直接迁移答案。

| 问题结构 | 可参考的编程模式 | 必须重新确认 |
|---|---|---|
| 网络与传播 | 图数据对齐、事件模拟、重复仿真 | 活跃机制、传播概率和配额定义 |
| 几何与测线 | 向量计算、插值、网格覆盖核验 | 坐标系、投影口径和边界条件 |
| 质量控制 | 序贯抽样、状态转移、风险模拟 | 成本口径、回流状态和抽样假设 |
| 光谱与信号 | 预处理、峰谷检测、回归、频域诊断 | 色散关系、有效波段和相关结构 |

使用案例前先回答：新题与案例的结构相似在哪里，关键假设哪里不同，如何用基线和
独立验证证明迁移没有失效。
