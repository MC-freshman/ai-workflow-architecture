# math-modeling-programmer

A programming-focused skill package for mathematical modeling competitions, upgraded to v1.5.

It covers data auditing, baseline and solver implementation, experiment tracking, numerical
validation, paper-ready figures, pattern adapters, behavior evaluation, reproducible execution,
and a restricted stdio MCP server. V1.5 adds composition-efficiency audits for render-time figure QA,
including legend orientation, sidecar whitespace, caption gaps, candidate layout scoring, PDF
geometry/font audits, and hash-bound visual review evidence. See `README_CN.md` for usage and stage gates.
